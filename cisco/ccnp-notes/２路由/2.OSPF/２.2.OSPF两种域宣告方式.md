可以。你这里说的 **OSPF 两种宣告方式**，指 Cisco 上最常见的两种：

1. **`network` 命令方式**
    
2. **接口下 `ip ospf` 方式**
    

这两个在 CCNP 里很重要。很多人会说“都是宣告网段”，但这个说法其实不够准确。你前面刚搞懂了 **Interface、Network、Area**，现在正好可以把这两个方式彻底弄明白。

---

# 一、先看两种配置长什么样

假设 R1：

```text
R1
├── G0/0 = 10.1.1.1/24
└── G0/1 = 10.2.2.1/24
```

我们希望：

```text
G0/0 → OSPF Area 0
G0/1 → OSPF Area 0
```

## 方法一：network 方式

```c
router ospf 1
 network 10.1.1.0 0.0.0.255 area 0
 network 10.2.2.0 0.0.0.255 area 0
```

---

## 方法二：接口方式

直接进入接口：

```c
interface g0/0
 ip ospf 1 area 0

interface g0/1
 ip ospf 1 area 0
```

---

# 二、最核心的区别

一句话：

> **`network` 是通过“匹配接口 IP”来启用 OSPF；`ip ospf` 是直接在指定接口上启用 OSPF。**

你可以理解成：

### network：

```text
我要找：
“哪些接口的 IP 符合这个范围？”

         ↓

找到接口

         ↓

在这些接口上启用 OSPF
```

### ip ospf：

```text
我现在就在 G0/0

         ↓

直接让 G0/0 运行 OSPF
```

---

# 三、network 命令到底干了什么？

这是最值得搞懂的。

例如：

```cisco
router ospf 1
 network 10.1.1.0 0.0.0.255 area 0
```

很多教材会说：

> “宣告 10.1.1.0/24。”

你可以这么记，但**真正的工作机制**是：

> Cisco 会拿 `10.1.1.0 0.0.0.255` 去匹配本机接口的 IP 地址。

假设 R1：

```text
G0/0 = 10.1.1.1/24
G0/1 = 10.1.2.1/24
G0/2 = 192.168.1.1/24
```

配置：

```cisco
router ospf 1
 network 10.1.1.0 0.0.0.255 area 0
```

Cisco 会检查：

```text
G0/0 = 10.1.1.1
       ↓
匹配 10.1.1.0/24
       ↓
启用 OSPF
       ↓
Area 0
```

而：

```text
G0/1 = 10.1.2.1
       ↓
不匹配
       ↓
不启用 OSPF
```

所以 `network` 命令的核心是：

> **匹配接口。**

---

# 四、为什么叫 wildcard mask？

例如：

```cisco
network 10.1.1.0 0.0.0.255 area 0
```

这里：

```text
10.1.1.0
0.0.0.255
```

后面的：

```text
0.0.0.255
```

是 **Wildcard Mask（通配符掩码）**。

规则：

```text
Wildcard = 255.255.255.255 - Subnet Mask
```

例如：

### /24

```text
255.255.255.0
```

对应：

```text
0.0.0.255
```

---

### /30

```text
255.255.255.252
```

对应：

```text
0.0.0.3
```

---

### /32

```text
255.255.255.255
```

对应：

```text
0.0.0.0
```

---

# 五、最容易考的：network 可以匹配多个接口

比如：

```text
R1

G0/0 = 10.1.1.1/24
G0/1 = 10.1.1.2/24
G0/2 = 10.1.1.3/24
```

然后：

```cisco
router ospf 1
 network 10.1.1.0 0.0.0.255 area 0
```

那么：

```text
10.1.1.0/24
       ↓
匹配
       ↓
G0/0
G0/1
G0/2
```

**三个接口都会启用 OSPF。**

这就是 network 方式的一个特点：

> **一条 network 命令可以匹配多个接口。**

---

# 六、而 ip ospf 是精准控制

如果你写：

```cisco
interface g0/0
 ip ospf 1 area 0
```

只影响：

```text
G0/0
```

不会影响：

```text
G0/1
G0/2
```

所以：

```text
network
   ↓
范围匹配

ip ospf
   ↓
接口精准配置
```

---

# 七、这就是两者最核心的区别

| |`network`|`ip ospf`|
|---|---|---|
|配置位置|OSPF进程下|接口下|
|核心机制|匹配接口IP|直接指定接口|
|是否使用 wildcard|是|否|
|是否可能一次匹配多个接口|是|否|
|精确控制|相对低|高|
|指定 Area|是|是|
|启用 OSPF|是|是|
|建立邻居|可以|可以|

---

# 八、一个很重要的例子

假设：

```text
R1

G0/0 = 10.1.1.1/24
G0/1 = 10.1.2.1/24
G0/2 = 10.1.3.1/24
```

你想：

```text
G0/0 → Area 0
G0/1 → Area 1
G0/2 → 不运行 OSPF
```

---

## network 方法

```cisco
router ospf 1
 network 10.1.1.0 0.0.0.255 area 0
 network 10.1.2.0 0.0.0.255 area 1
```

结果：

```text
G0/0 → Area 0
G0/1 → Area 1
G0/2 → 不运行
```

---

## interface 方法

```cisco
interface g0/0
 ip ospf 1 area 0

interface g0/1
 ip ospf 1 area 1
```

结果完全一样：

```text
G0/0 → Area 0
G0/1 → Area 1
G0/2 → 不运行
```

---

# 九、一个非常容易产生误解的地方

你可能会问：

> “既然两种方式最终结果一样，那为什么还要有两种？”

因为**配置便利性和控制粒度不同**。

例如一台路由器：

```text
G0/0 = 10.1.1.1/24
G0/1 = 10.1.2.1/24
G0/2 = 10.1.3.1/24
G0/3 = 10.1.4.1/24
G0/4 = 10.1.5.1/24
```

如果全部属于 Area 0：

```cisco
router ospf 1
 network 10.1.0.0 0.0.255.255 area 0
```

一条命令就可以匹配：

```text
10.1.1.1
10.1.2.1
10.1.3.1
10.1.4.1
10.1.5.1
```

非常方便。

如果用接口方式：

```cisco
interface g0/0
 ip ospf 1 area 0

interface g0/1
 ip ospf 1 area 0

interface g0/2
 ip ospf 1 area 0

interface g0/3
 ip ospf 1 area 0

interface g0/4
 ip ospf 1 area 0
```

就比较繁琐。

---

# 十、但是 network 方式有一个坑

比如：

```text
G0/0 = 10.1.1.1/24
G0/1 = 10.1.1.2/24
G0/2 = 10.1.1.3/24
```

你只想让：

```text
G0/0
```

运行 OSPF。

结果你写：

```cisco
network 10.1.1.0 0.0.0.255 area 0
```

那么：

```text
G0/0 ✓
G0/1 ✓
G0/2 ✓
```

全部被匹配。

这时候如果你只想精确匹配：

```text
G0/0 = 10.1.1.1
```

可以：

```cisco
router ospf 1
 network 10.1.1.1 0.0.0.0 area 0
```

因为：

```text
0.0.0.0
```

表示：

> **必须精确匹配这个 IP。**

---

# 十一、所以 /32 的 wildcard 很重要

例如：

```cisco
network 10.1.1.1 0.0.0.0 area 0
```

相当于：

> 只匹配 IP = 10.1.1.1 的接口。

而：

```cisco
network 10.1.1.0 0.0.0.255 area 0
```

相当于：

> 匹配所有 IP 在 10.1.1.0/24 范围内的接口。

所以：

```text
0.0.0.0
↓
精确匹配

0.0.0.255
↓
最后一段可以变化
```

---

# 十二、Loopback 上也一样

比如：

```cisco
interface loopback 0
 ip address 1.1.1.1 255.255.255.255
```

可以：

### network：

```cisco
router ospf 1
 network 1.1.1.1 0.0.0.0 area 0
```

### interface：

```cisco
interface loopback 0
 ip ospf 1 area 0
```

都可以让 Loopback 运行 OSPF。

不过 Cisco OSPF 对 Loopback 的默认处理还有一个重要细节：

> **Loopback 通常会以 /32 的形式被 OSPF 通告。**

这个以后讲 Router ID 和 Loopback 时你会经常碰到。

---

# 十三、两种方式最终会产生什么？

这是最重要的一点：

**两种方式不是两套不同的 OSPF。**

无论你用：

```cisco
network 10.1.1.0 0.0.0.255 area 0
```

还是：

```cisco
interface g0/0
 ip ospf 1 area 0
```

最终都是：

```text
接口启用 OSPF
      ↓
发送 Hello
      ↓
建立 Neighbor
      ↓
交换 LSA
      ↓
建立 LSDB
      ↓
SPF
      ↓
Routing Table
```

所以：

> **两种方法只是“怎么告诉 OSPF 哪些接口运行 OSPF”的不同方式。**

---

# 十四、还有一个 CCNP 很值得注意的细节

假设：

```cisco
router ospf 1
 network 10.1.1.0 0.0.0.255 area 0
```

匹配 G0/0。

但是 G0/0：

```text
没有邻居
```

这并不意味着：

> OSPF 没有工作。

它仍然可以：

- 启用 OSPF
    
- 发送 Hello
    
- 产生相关 LSA
    
- 将网络信息纳入 OSPF
    

只是没有其他 OSPF Router 和它建立邻接。

---

# 十五、和 passive-interface 结合起来就更有意思了

例如：

```text
R1
│
├── G0/0 → R2
│
└── G0/1 → LAN用户
```

你可能希望：

```text
G0/0 → 建立 OSPF Neighbor
G0/1 → 不建立 Neighbor，但是把这个 LAN 宣告给 OSPF
```

可以：

```cisco
router ospf 1
 network 10.1.1.0 0.0.0.255 area 0
 network 192.168.10.0 0.0.0.255 area 0
 passive-interface g0/1
```

于是：

```text
G0/0
 ↓
OSPF
 ↓
发送 Hello
 ↓
建立邻居

G0/1
 ↓
OSPF
 ↓
不发送 Hello
 ↓
不建立邻居
 ↓
但网络仍然可以被 OSPF 通告
```

这也是为什么你之前学的 **passive-interface** 很重要。

# 十六、考试怎么考？

CCNP 很喜欢这样问：

### 题型 1

```cisco
router ospf 1
 network 10.10.10.0 0.0.0.255 area 0
```

问：

> Which interfaces will run OSPF?

你要检查：

**哪些接口 IP 匹配这个 wildcard。**

---

### 题型 2

给你：

```text
G0/0 = 10.10.10.1/24
G0/1 = 10.10.20.1/24
G0/2 = 10.10.30.1/24
```

配置：

```cisco
network 10.10.0.0 0.0.255.255 area 0
```

答案：

```text
G0/0 ✓
G0/1 ✓
G0/2 ✓
```

因为都匹配：

```text
10.10.x.x
```

---

### 题型 3

问：

> Which configuration enables OSPF directly on an interface?

答案：

```cisco
interface g0/0
 ip ospf 1 area 0
```

# 十七、你现在最应该记住的东西

把这张表记住：

```text
             network方式                 interface方式
                 │                           │
                 ↓                           ↓
        router ospf 1              interface g0/0
                 │                           │
                 ↓                           ↓
      network + wildcard           ip ospf 1 area 0
                 │                           │
                 ↓                           ↓
        匹配接口的IP                 直接指定接口
                 │                           │
                 └──────────┬────────────────┘
                            ↓
                       启用 OSPF
                            ↓
                       指定 Area
                            ↓
                    Hello / Neighbor
                            ↓
                           LSA
                            ↓
                          LSDB
                            ↓
                           SPF
```

### 最核心的一句话：

> **`network` 是“通过 IP 匹配接口”；`ip ospf` 是“直接在接口上启用 OSPF”。两者最终实现的 OSPF 功能基本相同，主要区别在于配置方式和控制粒度。**

另外，你前面刚理解的 **Area** 在这里也正好体现出来：**Area 是配置到“接口”上的属性**。`network ... area 0` 只是通过匹配找到接口后把接口放进 Area 0；`ip ospf 1 area 0` 则是直接把指定接口放进 Area 0。
