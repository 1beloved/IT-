

### ① 查看 OSPF 基本信息

```cisco
show ip ospf
```

看：

- Router ID
    
- Process ID
    
- Area 数量
    
- SPF 计算次数
    
- LSA 数量
    

---

### ② 查看 OSPF 接口 ⭐

```cisco
show ip ospf interface
```

指定接口：

```cisco
show ip ospf interface g0/0
```

看：

- Area
    
- OSPF Cost
    
- Network Type
    
- Hello / Dead Timer
    
- DR / BDR
    
- Priority
    
- 邻居数量
    
- 接口状态
    

快速查看：

```cisco
show ip ospf interface brief
```

---

### ③ 查看 OSPF 邻居 ⭐⭐⭐

```cisco
show ip ospf neighbor
```

这是排查 OSPF 邻居最常用的命令。

重点看：

```text
FULL
2-WAY
EXSTART
EXCHANGE
LOADING
DOWN
```

例如：

```text
Neighbor ID     State
2.2.2.2         FULL/DR
3.3.3.3         FULL/BDR
```

---

### ④ 查看 OSPF 路由 ⭐⭐⭐

```cisco
show ip route ospf
```

重点识别：

```text
O       → 区域内
O IA    → 区域间
O E1    → 外部 E1
O E2    → 外部 E2
O N1    → NSSA E1
O N2    → NSSA E2
```

查看某一条：

```cisco
show ip route 5.5.5.5
```

例如：

```text
O E2 5.5.5.5/32 [110/20]
```

这里：

```text
110 = AD
20  = Metric
```

# ⑤ 查看整个 LSDB ⭐⭐⭐

```cisco
show ip ospf database
```

这个是你现在学 **LSA 1～5** 后必须掌握的。

---

### Type 1

```cisco
show ip ospf database router
```

**Router LSA**

---

### Type 2

```cisco
show ip ospf database network
```

**Network LSA**

---

### Type 3

```cisco
show ip ospf database summary
```

**Summary LSA**

---

### Type 4 ⭐

```cisco
show ip ospf database asbr-summary
```

**ASBR Summary LSA**

例如：

```cisco
show ip ospf database asbr-summary 4.4.4.4
```

---

### Type 5 ⭐

```cisco
show ip ospf database external
```

例如：

```cisco
show ip ospf database external 5.5.5.5
```

看外部路由的：

- Link State ID
    
- Advertising Router
    
- Metric
    
- Metric Type
    

---

# ⑥ 查看 OSPF 配置

```cisco
show running-config | section router ospf
```

例如：

```cisco
router ospf 1
 router-id 1.1.1.1
 network 10.1.1.0 0.0.0.255 area 0
 network 20.1.1.0 0.0.0.255 area 1
```

---

# ⑦ 查看 OSPF 重发布

你现在刚学到 ASBR 和 Type 5，这个也要会：

```cisco
show running-config | section router ospf
```

例如：

```cisco
router ospf 1
 redistribute static subnets
```

查看路由是否真的被重发布：

```cisco
show ip route ospf
```

再结合：

```cisco
show ip ospf database external
```

# ⑧ Debug OSPF ⭐

邻居建立过程：

```cisco
debug ip ospf adj
```

Hello：

```cisco
debug ip ospf hello
```

关闭：

```cisco
no debug ip ospf adj
```

或者直接：

```cisco
undebug all
```

**实验结束最好关掉 debug。**

# 🧠 最后你就背这 8 个

如果现在 CCNP 时间有限，我建议你优先记：

```cisco
show ip ospf
show ip ospf interface
show ip ospf interface brief
show ip ospf neighbor
show ip route ospf
show ip ospf database
show ip ospf database external
show ip route <prefix>
```

把它们理解成一条排错路线：

```text
OSPF运行了吗？
      ↓
show ip ospf
      ↓
接口正常吗？
      ↓
show ip ospf interface
      ↓
邻居起来了吗？
      ↓
show ip ospf neighbor
      ↓
路由学到了吗？
      ↓
show ip route ospf
      ↓
LSA到底是什么？
      ↓
show ip ospf database
      ↓
外部路由为什么这样选？
      ↓
show ip ospf database external
```

**这一套比单纯背几十条 `show` 命令有用得多。**你现在正在学 OSPF 的 LSA，所以接下来做实验时，最好养成一个习惯：**看到一条 OSPF 路由，不只看 `show ip route`，还要追到对应的 LSA。**这样 CCNP 的 OSPF 才算真正开始串起来。
