你现在可以把它理解成：

```
非OSPF路由
    ↓
静态路由 / BGP / EIGRP 等
    ↓
ASBR
    ↓
Redistribution（重发布）
    ↓
Type 5 LSA
    ↓
整个 OSPF 域传播
    ↓
其他 OSPF 路由器
    ↓
O E1 / O E2
```

例如：
![[Pasted image 20260912162107.png]]

```
        OSPF
┌─────────────────────┐
│                     │
R1 ─── R2 ─── R3 ─── R4 ───────── R5
                       │             │
                     ASBR          外部网络
                       │
                 5.5.5.5/32
```

R5 不运行 OSPF。

R4 有：

```
ip route 5.5.5.5 255.255.255.255 45.1.1.5
```

然后 R4：

```
router ospf 1
 redistribute static subnets
```

于是：

> **R4 把原来的静态路由重新发布成 Type 5 LSA。**

所以 R1/R2/R3 都能够学习到 `5.5.5.5/32`。

---

# 二、ASBR 到底是什么？

这个概念你现在应该彻底固定下来：

> **ASBR = 把外部路由引入 OSPF 的路由器。**

例如：

```
         非OSPF网络
             │
             │
             R5
             │
             R4
           ASBR
             │
       ┌─────┴─────┐
       │   OSPF    │
       │            │
      R3           R2
                    │
                    R1
```

R4 就是 ASBR。

注意：

**ASBR 并不是“必须有一个物理接口连接外部网络”。**

它的本质是：

> **这台路由器执行了外部路由的 Redistribution，并因此成为 ASBR。**

比如 R4 可以把：

- Static
- EIGRP
- BGP
- RIP
- Connected

等路由重发布进 OSPF。

---

# 三、Type 5 LSA 是这一章的核心

Type 5：

> **AS External LSA**

主要描述：

> **“OSPF 域外面存在一个网络，这个网络可以通过某个 ASBR 到达。”**

例如：

```
Type 5

LS ID              5.5.5.5
Advertising Router 4.4.4.4
Metric             20
Metric Type        E2
```

可以粗略理解成：

> **4.4.4.4 这个 ASBR 告诉 OSPF：外面有一个 5.5.5.5/32，我这里可以到，外部 Metric 是 20。**

---

# 四、Type 5 的一个非常重要特点

Type 5 **不属于某一个具体 Area**。

例如：

```
              Area 1
                 │
                 R4
                ASBR
                 │
                 │ Type 5
                 ↓
        ┌─────────────────┐
        │     Area 0      │
        └─────────────────┘
                 │
                 ↓
        ┌─────────────────┐
        │     Area 2      │
        └─────────────────┘
```

普通情况下，Type 5 可以在整个 OSPF 域内泛洪。

**但是注意：Stub Area 等特殊区域不能正常接收 Type 5。**

这个以后学 Stub/NSSA 时会重点出现。

# 五、你笔记里最重要的 E1 / E2

这是 CCNP 非常喜欢考的地方。

## E2：只看外部 Metric

默认情况下：

```
redistribute static subnets
```

产生的是：

> **E2**

假设：

```
R1 → R4 = 30
R2 → R4 = 20
R3 → R4 = 10

R4 → 外部网络 = 20
```

那么 E2：

```
R1 → 5.5.5.5 = 20
R2 → 5.5.5.5 = 20
R3 → 5.5.5.5 = 20
```

因为：

> **E2 默认只考虑外部 Metric，不把到 ASBR 的内部 OSPF cost 加进去。**

所以你看到：

```
O E2 5.5.5.5/32 [110/20]
```

这里的 `20` 就是外部 Metric。

# 六、E1：外部 + 内部

如果：

```
redistribute static subnets metric-type 1
```

就变成：

> **E1**

于是：

```
R1：30 + 20 = 50
R2：20 + 20 = 40
R3：10 + 20 = 30
```

也就是：

```
E1 Cost = 到ASBR的内部OSPF Cost + 外部Metric
```

所以：

```
E1
 ↓
考虑内部
+
考虑外部
```

而：

```
E2
 ↓
主要看外部Metric
```

# 七、这里纠正你笔记里的一个错误 ⚠️

你最后写的是：

> 类型1：仅计算外部路径开销  
> 类型2：同时计算外部和内部路径的累计开销

**这个写反了。**

正确的是：

|类型|计算|
|---|---|
|**E1**|内部 Cost + 外部 Metric|
|**E2**|主要使用外部 Metric|

所以你一定要改成：

> **E1 = 内外都算**  
> **E2 = 主要算外部**

记忆非常简单：

### E1

```
E1 = External + Internal
```

### E2

```
E2 = External
```

# 八、再纠正一个容易产生误解的地方

你笔记里写：

> “类型一和类型二，类型一计算更精确，所以优先选择类型一。”

这个说法**作为入门理解可以，但 CCNP 考试最好记得更精确一点**。

OSPF 在选择外部路由时，**E1 和 E2 有明确的外部路由选路规则**。特别是在 E2 场景下，如果多个路径的外部 Metric 相同，还需要比较到 ASBR 的内部路径成本。

因此不要简单背成：

> “E1 永远比 E2 优先。”

更稳妥的理解是：

> **如果存在 E1 和 E2 的候选外部路由，OSPF 的外部路由选路有专门的 E1/E2 比较规则；不要把它简单理解成“E1 永远优先”。**

# 九、Type 4 和 Type 5 再串一次

你刚刚上一轮学的是 Type 4，这里正好连起来。

假设：

```
                 Area 0
        R1 ───── R2
                  │
                Area 1
                  │
                 R4
                ASBR
                  │
            5.5.5.5
```

这里：

### Type 5

告诉：

> **“外面有 5.5.5.5/32。”**

### Type 4

告诉：

> **“4.4.4.4 这个 ASBR 在哪里，怎么到它。”**

所以你可以记成：

```
Type 5
   ↓
外部网络在哪里？

Type 4
   ↓
ASBR在哪里？
```

# 十、但是你笔记里“4类依附于5类”要谨慎理解

你写：

> “OSPF的4类LSA依附于5类LSA，两者具有关联性”

**这个作为理解可以，但不要把它背成“Type 4 是 Type 5 的附属 LSA”。**

更准确的是：

> **Type 4 的作用是让其他 Area 的路由器能够计算到 ASBR 的路径，而 Type 5 描述外部网络。**

两者经常一起出现：

```
Type 4 → 找 ASBR
Type 5 → 找外部网络
```

例如：

```
R1
 │
 │ Type 4
 ↓
ASBR 4.4.4.4
 │
 │ Type 5
 ↓
5.5.5.5/32
```

这样就非常清楚了。

# 十一、最后给你一张 CCNP 必背表

|知识点|一句话|
|---|---|
|**ASBR**|把外部路由引入 OSPF|
|**Redistribution**|把其他来源的路由重新发布进 OSPF|
|**Type 5**|描述外部路由|
|**Type 4**|帮助其他 Area 找到 ASBR|
|**E2**|默认外部 Metric，默认值通常为 20|
|**E1**|内部 Cost + 外部 Metric|
|**E2 默认**|不直接累加内部 Cost|
|**E1**|会累加到 ASBR 的内部 Cost|
|`redistribute static subnets`|把静态路由重发布进 OSPF|
|`metric-type 1`|生成 E1|
|`metric-type 2`|生成 E2|

你现在把这一章压缩成一句话就是：

> **外部路由通过 ASBR 重发布进 OSPF，形成 Type 5；默认是 E2，只看外部 Metric；改成 E1 后，要把到 ASBR 的内部 OSPF Cost 也算进去。**
