

**1. 只能重分发路由表中存在的路由**  
```
这是最基本的前提，路由必须先在路由表里，才能被重分发。
```
	
**2. 具有方向性，影响其他设备、不影响自身**  
```
补充一点：方向性是指 `redistribute A` 配在 B 的进程下，只是把 A 的路由注入 B。想让 A 也学到 B 的路由，要在 A 的进程下再配一条反向的，这就是双向重分发。ASBR 自己的路由表不变，路由仍显示为原协议。
```

**3. 还会重分发该协议对应的直连接口：对，这是容易漏掉的考点**  
```
比如 `redistribute ospf 1` 时，运行 OSPF 的接口所在网段（直连网络）也会一起进入目标协议，即使这些网段在路由表里显示为 `C`。
```

**4. EIGRP 重分发要手动指定 5K 值：大体对，但有两点要注意**

```
- 术语上，这里指的是五个度量参数（带宽、延迟、可靠性、负载、MTU），不是 K1 到 K5 这五个权重系数。写笔记时最好分清楚，K 值是计算公式里的系数，这五个是输入的度量数值。
- 例外不止直连和静态：EIGRP 不同 AS 之间互相重分发时，度量会自动转换，也不需要手动指定。所以规则可以记成：重分发 OSPF、RIP、BGP 等其他协议进 EIGRP 时必须指定，重分发直连、静态、其他 EIGRP 进程时可以不指定。
```

**5. OSPF 重分发要加 `subnets`，否则子网会丢失**


## 核心原理：重分发的依据是路由表

重分发不是把一个协议的数据库复制给另一个协议。ASBR 只把路由表（RIB）里由源协议学到的最佳路由，交给目标协议，由目标协议按自己的规则重新通告。因此：

- 源协议的路由要先出现在路由表里，才能被重分发。
- 重分发后，ASBR 自己路由表里的路由仍属于原协议（比如 `D`），不会变成 `O E2`。
- 源协议里被过滤或不是最佳路径的路由，不会被重分发。

## 为什么要设种子度量（seed metric）

不同协议的度量标准不兼容：OSPF 是**带宽算出的 cost**，EIGRP 是带宽、延迟等组成的复合度量，RIP 是跳数。度量无法直接换算，所以目标协议要自己给这些路由指定一个起始值。

考试要记的默认值：

|目标协议|默认种子度量|
|---|---|
|OSPF|20（重分发 BGP 时为 1）|
|EIGRP|无，必须手动指定|
|RIP|无，必须手动指定|

EIGRP 和 RIP 没有默认值，等于度量为无穷大，**路由不会进入协议**。OSPF 有默认值，所以不写 `metric` 也行，这是常考陷阱。

## 为什么 OSPF 要加 `subnets`

`redistribute` 到 OSPF 时默认按有类别处理，**只重分发主类网络，子网会丢失。加上 `subnets` 才会包含所有子网。这是 OSPF 的历史遗留行为**，考试和实验里都常见。

## 为什么是 E1 和 E2

重分发进 OSPF 的路由成为外部路由（Type 5 LSA），有两种度量计算：

- **E2（默认）**：度量在整个 OSPF 域内保持不变，等于种子度量。适合只有一个出口的情况。
- **E1**：度量 = 种子度量 + 到 ASBR 的内部 cost。适合有多个 ASBR、需要选最近出口的情况。

选路优先级：O、O IA 优于 E1，E1 优于 E2。相同类型再比度量。

## 为什么会有 AD 的问题（重点）

AD 只对本机有意义，用来在不同协议之间选最优路由。重分发会引发两类常见问题：

**1. 外部路由 AD 不同**

- EIGRP 内部 AD 90，外部 AD 170。
- OSPF 内部外部都是 110。
- 所以 EIGRP 从 OSPF 学到的路由是 `D EX`（170），OSPF 从 EIGRP 学到的是 `O E2`（110）。

**2. 双向重分发时的路由反馈**  
多个边界路由器双向重分发时，路由可能从 A 域进入 B 域，又绕回 A 域。这时如果 OSPF（110）优于 EIGRP 外部路由（170），某些路由器会选到经过重分发的路径，造成次优路径或环路。

## 为什么用 tag 加 route-map 防环

tag 是随路由传递的标记，重分发时打上，在另一个方向发现这个标记就拒绝，路由就不会被送回原来的域。这比按前缀过滤更灵活，因为不需要知道具体前缀。

其他考试中可能考的防环手段：

- 用 `distance` 调整外部路由的 AD。
- 用 prefix-list 结合 route-map 过滤。

## 为什么 OSPF 重分发到 EIGRP 默认只带内部路由

重分发 OSPF 到 EIGRP 时，默认只带 OSPF 内部路由（O、O IA）。需要用 `match external 1 external 2` 才会带外部路由。这是防止外部路由在多个协议之间无限循环。







# **配置**


## 1. OSPF → EIGRP

```
router eigrp 100
 redistribute ospf 1 metric 10000 100 255 1 1500
```

- EIGRP 的种子度量有 5 个参数：带宽（kbps）、延迟（十微秒）、可靠性、负载、MTU。从 OSPF 重分发进来必须指定，否则路由不会进入 EIGRP。也可以用 `default-metric` 统一设置。
- 在 EIGRP 里这些路由显示为 `D EX`，AD 为 170。
- **默认只重分发 OSPF 的内部路由**（O、O IA）。要把 OSPF 外部路由也带进去，需要加 match 参数：

```
redistribute ospf 1 match internal external 1 external 2 metric 10000 100 255 1 1500
```

## 2. EIGRP → OSPF

```
router ospf 1
 redistribute eigrp 100 subnets /metric 20 metric-type 1(可不选)
```

- **`subnets` 一定要加**，不加的话只会重分发有类别的主网络，子网会丢失。
- `metric` 是种子度量（默认 20），`metric-type` 可选 1 或 2（默认 E2）。
- 在 OSPF 里显示为 `O E2`（或 `O E1`），AD 为 110。
- EIGRP 内部和外部路由默认都会被重分发。

## 3. 双向重分发要防环

如果在多台边界路由器上做双向重分发，路由可能被绕回原协议，形成环路或次优路径。常见做法是重分发时打 tag，再在另一个方向拒绝带这个 tag 的路由：

```
route-map EIGRP-TO-OSPF deny 10
 match tag 100
route-map EIGRP-TO-OSPF permit 20
 set tag 200
!
route-map OSPF-TO-EIGRP deny 10
 match tag 200
route-map OSPF-TO-EIGRP permit 20
 set tag 100
!
router ospf 1
 redistribute eigrp 100 subnets route-map EIGRP-TO-OSPF
router eigrp 100
 redistribute ospf 1 route-map OSPF-TO-EIGRP metric 10000 100 255 1 1500
```

## 4. 验证命令

- `show ip protocols`：看重分发配置
- `show ip route`：看 `D EX` 和 `O E2`
- `show ip ospf database external`：看生成的 Type 5 LSA
- `show ip eigrp topology`：看 EIGRP 拓扑表

你可以自己搭一个简单拓扑：R1 跑 OSPF，R2 做 ASBR，R3 跑 EIGRP，先单向再双向重分发，对比路由表和 tag 的变化。
