Prefix-list 语法

**口诀**：

- 斜杠前面定网段
- ge 表示掩码长度大于等于多少
- le 表示掩码长度小于等于多少

**基本格式**：

```cisco
ip prefix-list NAME seq 10 permit 10.0.0.0/8 ge 16 le 24
```

语法拆开看：

| 字段             | 含义                                                            |
| -------------- | ------------------------------------------------------------- |
| ip prefix-list | 固定命令，表示创建或修改 IPv4 前缀列表                                        |
| NAME           | Prefix-list 名字，用来被 Distribute-list、Filter-list 或 Route-map 调用 |
| seq 10         | 序号，决定匹配顺序；不写时设备会自动生成(**默认五开始，步长为五)**                          |
| permit / deny  | 匹配后允许或拒绝，最终含义取决于被谁调用                                          |
| 10.0.0.0/8     | 这个8表示的是这前面八位必须相同                                              |
| ge 16          | 允许匹配的最小掩码长度是 /16，≥                                            |
| le 24          | 允许匹配的最大掩码长度是 /24，≤                                            |


这条命令的完整含义是：匹配属于 10.0.0.0/8 范围内，**并且**掩码长度在 /16 到 /24 之间的路由。

Prefix-list 是按 seq 从小到大依次匹配的。匹配到第一条后就停止，不会继续往后看。

```cisco
ip prefix-list TEST seq 10 deny 10.1.20.0/24
ip prefix-list TEST seq 20 permit 10.1.0.0/16 ge 24 le 24
ip prefix-list TEST seq 30 permit 0.0.0.0/0 le 32
```

**说明**

以上的 TEST 为例：

| 被检查的前缀         | 匹配结果   | 原因                                       |
| -------------- | ------ | ---------------------------------------- |
| 10.1.20.0/24   | deny   | 先命中 seq 10，直接停止                          |
| 10.1.30.0/24   | permit | 不命中 seq 10，命中 seq 20                     |
| 10.1.30.0/25   | permit | 不命中 seq 20，因为 seq 20 只允许 /24；继续命中 seq 30 |
| 192.168.1.0/24 | permit | 命中 seq 30 的任意 IPv4 路由                    |

如果想测试某个前缀会不会被 Prefix-list 匹配，可以用：

```cisco
show ip prefix-list TEST 10.1.20.0/24 first-match
show ip prefix-list TEST 10.1.30.0/24 first-match
```

如果想看某个前缀下面有哪些更具体条目，可以用：

```cisco
show ip prefix-list TEST 10.1.0.0/16 longer
```

**常见写法**：

| 写法                     | 含义                        |
| ---------------------- | ------------------------- |
| 10.0.0.0/8             | 只匹配 10.0.0.0/8 本身         |
| 10.0.0.0/8 le 16       | 匹配 10.0.0.0/8 到 /16       |
| 10.0.0.0/8 ge 16       | 匹配 10.0.0.0/8 下 /16 到 /32 |
| 10.0.0.0/8 ge 16 le 24 | 匹配 /16 到 /24              |
| 0.0.0.0/0              | 只匹配默认路由                   |
| 0.0.0.0/0 le 32        | 匹配所有 IPv4 路由              |
|                        |                           |

**匹配的时候最好不要超过掩码的长度，比如10.0.0.0/8 ge 3不要尝试在规定了8的前提下冲突**

示例：只匹配 10.1.0.0/16 本身。

```cisco
ip prefix-list ONLY-10-1 permit 10.1.0.0/16
```

示例：匹配 10.1.0.0/16 下所有 /24 到 /32 明细。

**查看与清除计数器**：

```cisco
show ip prefix-list
show ip prefix-list DETAIL-10-1
show ip prefix-list detail DETAIL-10-1
show ip prefix-list DETAIL-10-1 10.1.1.0/24 first-match
show ip prefix-list DETAIL-10-1 10.1.0.0/16 longer
clear ip prefix-list DETAIL-10-1


```
