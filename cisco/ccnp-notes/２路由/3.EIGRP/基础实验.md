基础配置
```
R1

interface Loopback0
 ip address 1.1.1.1 255.255.255.255
 
interface GigabitEthernet0/0
 ip address 10.1.1.1 255.255.255.0
	no shutdown

router eigrp 90
 network 1.1.1.1 0.0.0.0
 network 10.1.1.0 0.0.0.255
 eigrp router-id 1.1.1.1

R2
interface Loopback0
 ip address 2.2.2.2 255.255.255.255

interface GigabitEthernet0/0
 ip address 10.1.1.2 255.255.255.0
	no shutdown
interface GigabitEthernet0/1
 ip address 20.1.1.2 255.255.255.0
	no shutdown

router eigrp 90
 network 2.2.2.2 0.0.0.0
 network 10.1.1.0 0.0.0.255
 network 20.1.1.0 0.0.0.255
 eigrp router-id 2.2.2.2

R3

interface Loopback0
 ip address 3.3.3.3 255.255.255.255

interface GigabitEthernet0/0
 ip address 20.1.1.3 255.255.255.0
	no shutdown
	

router eigrp 90
 network 3.3.3.3 0.0.0.0
 network 20.1.1.0 0.0.0.255
 eigrp router-id 3.3.3.3


```

![[Pasted image 20260918201946.png]]
抓包R1发现R2与R3的20.1.1.0的路由包.
除了Hello Ack确认的时候是单播，其余的时候都是组播到**224.0.0.10**
OSPF的组播224.0.0.5/224.0.0.6
EIGRP的协议号为**88**，并且EIGRP只要收到hello 报文就认定邻居建立成功，邻接速度非常快。

**而Hello报文的两种类型为普通Hello和Ack类型的。其中Ack类型的报文格式与Hello格式的一摸一样，只有Acknowledge不一样，其中的值为上一个Update报文的Sequence。**
