EIGRP命名模式（Named Mode）是思科较新的EIGRP配置方式，它将原本分散在**路由器配置模式**和**接口配置模式**下的EIGRP参数，全部集中到一个**层级化的单一配置结构**中。对于现代网络，尤其是需要同时运行IPv4/IPv6或使用VRF的场景，命名模式在管理和扩展性上优势明显。

### 为什么要用命名模式？

与传统的经典模式相比，命名模式主要解决了以下痛点：

- **配置集中化**：经典模式下，接口相关的参数（如认证、汇总、计时器）必须进入物理或逻辑接口下配置。命名模式将所有EIGRP参数（包括接口参数）都收拢在`router eigrp`的层级下，通过`af-interface`子模式来定义接口行为。
    
- **原生支持多地址族与VRF**：经典模式要为IPv4和IPv6分别创建独立的EIGRP进程，且IPv6 EIGRP不支持VRF。命名模式**仅需创建一个EIGRP实例**，即可同时承载IPv4、IPv6以及多个VRF，管理起来非常清晰。
    
- **新特性的唯一入口**：思科许多新功能（如**Wide Metrics**宽度量值、IPv6 VRF Lite、路由标记增强）**仅在命名模式下支持。
    

### 核心配置架构：三种模式

命名模式通过三个嵌套的配置模式来组织命令，这是理解它的关键：

1. **地址族配置模式 (`config-router-af`)**：这是命名模式的核心入口。你需要在这里指定`address-family ipv4 unicast autonomous-system 1`来创建并启动进程。常用的全局参数如`router-id`、`network`、`neighbor`以及`maximum-prefix`都在这里配置。
    
2. **地址族接口配置模式 (`config-router-af-interface`)**：进入这个模式（例如`af-interface GigabitEthernet 0/0`）后，你配置的是**以前在物理接口下才能敲的命令**。比如**EIGRP认证**（`authentication mode`）、**水平分割**（`split-horizon`）、**接口汇总**（`summary-address`）和**Hello/Hold计时器**都在这里定义。
    
3. **地址族拓扑配置模式 (`config-router-af-topology`)**：这个模式针对EIGRP的**拓扑表**进行操作，主要用于路由控制。你在此配置**重分发**（`redistribute`）、**管理距离**（`distance`）、**偏移列表**（`offset-list`）以及**方差**（`variance`）等

```
router eigrp TEST
 address-family ipv4 unicast autonomous-system 1
 address-family ipv6 unicast autonomous-system 1
```


```
router eigrp TEST
 address-family ipv4 vrf CUSTOMER_A autonomous-system 1
 address-family ipv4 vrf CUSTOMER_B autonomous-system 1
```
