# 一、静态重分布（最简单最好理解）

由于默认路由在R3上并没有加入到EIGRP，所以其它路由并没有学习到去往ISP的路径。
此时可以重分布路由，把这条静态路由加入到EIGRP中
```
R3(config)#router eigrp 90

R3(config-router)#redistribute static

```
![[Pasted image 20260922183901.png]]
此时可以看到这条默认路由也被学习到了。

# 二、对内接口汇总默认路由

**ip summary-address eigrp <AS号> <汇总地址> <掩码>**

由于是R3知道去ISP的路径，其它不知道，所以可以通过路由汇总，把所有的默认路由都汇总到接口g0/0，也就是R3路由器上，然后R3再去玩ISP

```
int g0/0    //需要先进入接口

ip summary-address eigrp 90 0.0.0.0 0.0.0.0
```
