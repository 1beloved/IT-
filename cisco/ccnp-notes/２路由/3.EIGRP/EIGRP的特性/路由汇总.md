路由汇总分为**手动**和**自动**两种方式，自动不适用，汇总的范围**不精确**

汇总效果仅影响**该接口方向**传递的路由

#### **ip summary-address eigrp <AS号> <汇总地址> <掩码>**

比如把﻿10.1.1.x/32的路由汇总到一起
```c
int g0/0    //需要先进入接口

ip summary-address eigrp 90 10.1.1.0 255.255.255.0


```

![[Pasted image 20260922170221.png]]

R3上有五条环回路由，我们用默认路由把这些地址加入到EIGRP
配置如下
```
router eigrp 90
 network 0.0.0.0
 network 10.1.2.0 0.0.0.255
 network 192.168.2.0
 passive-interface GigabitEthernet0/1
 eigrp router-id 3.3.3.3

```

然后
```
ip summary-address eigrp 90 20.1.1.0 255.255.255.0
```
把路由汇总加入进去。
