	**Diffusing Update Algorithm，扩散更新算法**

## 一、DUAL 的核心目标

DUAL 要解决两个问题：

1. **如何保证计算出的路径无环路？**
    
2. **当拓扑变化时，如何以最快速度收敛，且避免环路？**
    

DUAL 是：**通过“可行距离”和“报告距离”的比较，预先筛选出无环的备份路径（可行后继）**。只要存在可行后继，路由器就可以立即切换，无需询问邻居，从而实现瞬时收敛。

---

## 二、关键术语

在深入 DUAL 之前，必须先明确以下术语：

| 术语       | 英文                                              | 含义                                                        |
| -------- | ----------------------------------------------- | --------------------------------------------------------- |
| **后继**   | Successor                                       | 到达目的地的**最佳路径**的下一跳路由器。它被放入路由表，是当前使用的路径。                   |
| **可行后继** | Feasible Successor（FS）                          | 到达目的地的**备份路径**的下一跳路由器。它被放入拓扑表，满足可行条件，可随时接替后继。             |
| **可行距离** | Feasible Distance（FD）                           | 从本路由器到目的地的**最小 Metric 值**。即当前最佳路径的 Metric。                |
| **报告距离** | Reported Distance（RD）/（Advertised Distance, AD） | 邻居路由器到达目的地的 Metric 值。也叫**通告距离（Advertised Distance, AD）**。 |
| **可行条件** | Feasible Condition（FC）                          | 判断一个邻居能否成为可行后继的条件：**AD < FD**。                            |
| **拓扑表**  | Topology Table                                  | 存放所有到达目的地的路径信息，包括后继和可行后继。                                 |
| **被动状态** | Passive State                                   | 路由处于稳定状态，有后继，没有正在进行的扩散计算。                                 |
| **活动状态** | Active State                                    | 路由丢失后继，正在向邻居发送 Query，等待 Reply，进行扩散计算。                     |
