

# BGP 策略工具

> BGP 的核心是**策略**：先用工具**匹配**路由，再用 route-map **设置属性**，最后影响 Best Path。

## 一、策略工具总览

|工具|作用|
|---|---|
|**Prefix-list**|匹配路由前缀|
|**AS-path ACL**|匹配 AS_PATH（正则）|
|**Community-list**|匹配 Community|
|**Extcommunity-list**|匹配 Extended Community|
|**Route-map**|组合 `match` / `set`，是策略核心|
|**Filter-list**|调用 AS-path ACL|
|**Distribute-list**|传统过滤工具，BGP 中**较少作为首选**|
|**Maximum-prefix**|限制邻居接收的前缀数量|

处理流程：

```
邻居路由 → Prefix-list / AS-path / Community 匹配 → Route-map 设置属性
        → (LocalPref / MED / Community / Weight) → BGP Best Path
```

## 二、入站策略与出站策略

|方向|作用对象|常见用途|
|---|---|---|
|**Inbound**|从邻居**收到**的路由|设置 Weight、LocalPref，过滤前缀|
|**Outbound**|**发给**邻居的路由|过滤通告，设置 MED、AS_PATH Prepend、Community|

**入站策略影响本地如何选路；出站策略影响对端如何看待本 AS 通告的路径。**

入站提高 Local Preference：

```
route-map ISP1-IN permit 10
 set local-preference 200
router bgp 65001
 neighbor 203.0.113.1 route-map ISP1-IN in
```

出站 AS Path Prepend：

```
route-map ISP2-OUT permit 10
 set as-path prepend 65001 65001 65001
router bgp 65001
 neighbor 198.51.100.1 route-map ISP2-OUT out
```

两个示例的 `permit 10` 都**没有 match，等于匹配所有路由**，所以不会丢路由。

## 三、Route-map 行为细节

理解 route-map 要同时看 **permit/deny、sequence、match、set**。

```
route-map NAME permit 10
 match ...
 set ...
route-map NAME permit 20
 match ...
 set ...
route-map NAME permit 100
```

### 关键规则

|规则|说明|
|---|---|
|按 **sequence 从小到大**匹配|命中某一条后**通常不再往下匹配**|
|`permit` + match 成功|允许通过，并执行 `set`|
|`deny` + match 成功|**拒绝**通过，不执行 `set`|
|没有任何 `match`|**匹配所有路由**|
|没有匹配到任何 sequence|命中**隐式 deny**|
|多个**不同类型**的 `match`|通常是 **AND** 关系|
|同一类 `match` 里的多个对象|通常是 **OR** 关系|

### 常见坑：忘了兜底

```
route-map SET-LP permit 10
 match ip address prefix-list IMPORTANT
 set local-preference 200
```

只写这一条，**没匹配 IMPORTANT 的其他路由会被隐式 deny，邻居路由可能大量消失**。常见做法是在最后加兜底：

```
route-map SET-LP permit 100
```

这样其他路由继续通过，只是不修改属性。

### 不同使用位置的含义

|使用位置|典型作用|
|---|---|
|`neighbor x route-map NAME in`|控制接收哪些路由，或修改收到路由的属性|
|`neighbor x route-map NAME out`|控制通告哪些路由，或修改发出路由的属性|
|`redistribute static route-map NAME`|控制哪些静态路由重分发进 BGP|
|`aggregate-address ... attribute-map NAME`|修改聚合路由的属性|

### 策略修改后要软刷新

```
clear ip bgp 192.0.2.1 soft in
clear ip bgp 192.0.2.1 soft out
```

## 四、Prefix-list 过滤

只向 ISP 通告本 AS 的合法前缀：

```
ip prefix-list OUT-PREFIX permit 203.0.113.0/24

route-map BGP-OUT permit 10
 match ip address prefix-list OUT-PREFIX

router bgp 65001
 neighbor 192.0.2.1 route-map BGP-OUT out
```

这里**没有兜底条目是有意的**：隐式 deny 正好把其他前缀都挡住。

拒绝默认路由，允许其他路由：

```
ip prefix-list NO-DEFAULT deny 0.0.0.0/0
ip prefix-list NO-DEFAULT permit 0.0.0.0/0 le 32

router bgp 65001
 neighbor 192.0.2.1 prefix-list NO-DEFAULT in
```

### `ge` 和 `le`

|写法|匹配范围|
|---|---|
|`permit 10.0.0.0/8`|**只匹配** 10.0.0.0/8 本身|
|`permit 10.0.0.0/8 le 24`|/8 到 /24，**包括 /8 本身**|
|`permit 10.0.0.0/8 ge 16`|/16 到 /32，**不包括 /8 到 /15**|
|`permit 10.0.0.0/8 ge 16 le 24`|/16 到 /24|
|`permit 0.0.0.0/0 le 32`|**匹配所有 IPv4 前缀**|

### 常见模板

```
! 只允许默认路由
ip prefix-list DEFAULT-ONLY permit 0.0.0.0/0

! 允许所有路由
ip prefix-list ANY permit 0.0.0.0/0 le 32

! 只允许 203.0.113.0/24 范围内 /25 到 /32 的明细（不含 /24 本身）
ip prefix-list PUBLIC-DETAIL permit 203.0.113.0/24 ge 25 le 32

! 拒绝默认路由，允许其他所有路由
ip prefix-list NO-DEFAULT deny 0.0.0.0/0
ip prefix-list NO-DEFAULT permit 0.0.0.0/0 le 32
```

**Prefix-list 也有隐式 deny**。写过滤策略时要明确最后是否需要 `permit` 兜底。

## 五、AS-path ACL

AS-path ACL 用**正则**匹配 AS_PATH。

### 常见符号

|符号|含义|
|---|---|
|`_`|**AS 边界**，可表示空格、起止、括号等边界|
|`^`|开头|
|`$`|结尾|
|`.`|任意字符|
|`*`|重复 0 次或多次|
|`+`|重复 1 次或多次|

### 示例

匹配**起源于** AS 65010 的路由：

```
ip as-path access-list 10 permit _65010$
```

匹配**经过** AS 65020 的路由：

```
ip as-path access-list 20 permit _65020_
```

调用：

```
route-map MATCH-AS permit 10
 match as-path 10
 set local-preference 150
```

### 常用正则模板

|需求|正则|
|---|---|
|本 AS 本地产生，AS_PATH 为空|`^$`|
|起源于 AS 65010|`_65010$`|
|经过 AS 65010|`_65010_`|
|直接来自 AS 65010 **且由它起源**|`^65010$`|
|路径以 AS 65010 开头|`^65010_`|

拒绝经过**私有 16-bit AS**（64512–65534）：

```
ip as-path access-list 30 deny _(6451[2-9]|645[2-9][0-9]|64[6-9][0-9][0-9]|65[0-4][0-9][0-9]|655[0-2][0-9]|6553[0-4])_
ip as-path access-list 30 permit .*
```

查看匹配结果：

```
show ip bgp regexp _65010$
show ip bgp regexp ^$
```

### 常见用途

- 只接受客户**自己起源**的路由。
- 拒绝经过某些 AS 的路由。
- 给特定 AS 来源的路由设置 LocalPref。
- 检查私有 AS 是否泄漏。

## 六、易错点速览

- route-map、prefix-list、AS-path ACL **都有隐式 deny**，写完要想清楚末尾要不要 `permit` 兜底。
- route-map 没有 `match` 等于**匹配所有**。
- 不同类型 match 是 **AND**，同类型多个对象是 **OR**。
- `deny` 命中后**不执行 set**，路由直接被拒绝。
- 入站设置 Weight / LocalPref，出站设置 MED / Prepend / Community。
- 策略改完要 **soft in / soft out**。
- 匹配“起源于某 AS”用 `_AS$`，**不要漏掉 `$`**。
