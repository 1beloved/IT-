## 一、BGP 里产生默认路由有三种方式

|方式|作用范围|前提条件|是否进本机 BGP 表|
|---|---|---|---|
|`neighbor x default-originate`|只发给该邻居|无条件（可加 route-map 设条件）|不进|
|`network 0.0.0.0`|所有邻居|路由表里必须已有精确的 0.0.0.0/0|进|
|`redistribute static` 加 `default-information originate`|所有邻居|路由表里有默认路由，且两条命令都要配|进|

### 1. `neighbor default-originate`

- 针对单个邻居，不同邻居可以发不同内容，最灵活
    
- 无条件产生，ISP 常用它给客户下发默认路由
    
- 本机 `show ip bgp` 看不到这条路由，要到接收端才能看到
    
- 要加条件时用 route-map：
    
    ```cisco
    neighbor 10.0.1.2 default-originate route-map COND
    ```
    
    route-map 里的 `match ip address prefix-list` 匹配的是**本机路由表里存在的前缀**，匹配成功才发。条件路由消失，默认路由随即撤销
    

### 2. `network 0.0.0.0`

```cisco
ip route 0.0.0.0 0.0.0.0 Null0
router bgp 65002
 network 0.0.0.0
```

- 和其他 `network` 一样，要求路由表有精确匹配，所以常配一条指向 Null0 的静态默认路由来"撑住"
- 会发给**所有邻居**，粒度粗，容易误发给不该收的对象

### 3. `redistribute static` 的坑

BGP 的 `redistribute static` **不会带上默认路由**，这点和 OSPF 一样，必须额外配：

```cisco
router bgp 65002
 redistribute static
 default-information originate
```

少了第二条，默认路由就是不出去。

## 二、`default-originate` 的几个关键细节

1. **绕过出站 prefix-list**：邻居上配了只放行少量前缀的出站 prefix-list，默认路由依然会发出去。要对这条默认路由做策略，必须在 `default-originate route-map` 里做（比如 `set metric`、`set as-path prepend`），不能指望出站过滤。
2. **无条件的风险**：ISP 自己的上游断了，仍然向客户下发默认路由，客户流量会被引进来然后丢掉。所以正式环境建议加 route-map 做条件，绑定一个上游一定存在的前缀。
3. **改完要刷新**：修改 `default-originate` 或 route-map 后，需要 `clear ip bgp x.x.x.x soft out` 才会重新发送。
4. **IPv6 要在地址族下配**：IPv6 的 `default-originate` 要先 `neighbor x activate`，并写在 `address-family ipv6` 里，写在全局下无效。

## 三、接收端要注意的

### 1. 默认路由和普通路由没有区别

接收端收到的 0.0.0.0/0 就是一条普通 BGP 路由，走正常的路径选择：

- 需要下一跳可达，否则没有 `*`，不会成为有效路由
- eBGP 的 AD 是 20，iBGP 是 200，会和 IGP 比较
- 选路时同样比较 weight、LOCAL_PREF、AS_PATH、MED 等

### 2. 默认路由优先级最低，靠的是最长前缀匹配

你的实验里，R1 同时有：

```text
B  8.8.8.8/32 via 10.0.1.1
B* 0.0.0.0/0  via 10.0.1.1
```

去 8.8.8.8 走 /32，其他走默认。这是前缀长度决定的，和 BGP 属性无关。

### 3. 接收前一定要过滤

不加限制地接受邻居发来的默认路由，会引入风险：

```cisco
ip prefix-list DEF-ONLY seq 5 permit 0.0.0.0/0

router bgp 65001
 neighbor 10.0.1.1 prefix-list DEF-ONLY in    ! 只收默认路由
```

- 只想要默认路由的话，入站只放行 0.0.0.0/0，其他一概不收，省内存也更安全
- 反过来，**不想要**默认路由时，用 `ip prefix-list ... deny 0.0.0.0/0` 拒掉

### 4. 默认路由不会因为 BGP 传播而安全

eBGP 学到的默认路由，会按常规规则继续通告给其他 eBGP 邻居。如果你是多出口的企业，把 ISP A 给的默认路由原样发给 ISP B，会造成**路由泄露**，把自己变成了中转。所以出站必须只放行自己的前缀：

```cisco
neighbor <ISP> prefix-list MY-PREFIXES out
```

## 四、在你这个拓扑里的具体注意点

```text
ISP (65002) ── R1 (65001, BGP+OSPF) ── SW ── R2 / R3
```

### 1. 默认路由从 BGP 变成 OSPF

R1 的 `default-information originate` 没带 `always`，它依赖本机路由表里有默认路由，而这条路由正来自 BGP。好处是 ISP 断了，R2、R3 的默认路由会自动撤销。但这里有一个限制：它只对**非 OSPF 来源**的默认路由生效，BGP 来源是合格的。

### 2. 不要把 BGP 默认路由用 `redistribute` 又配 `default-information`

BGP 到 OSPF 的方向，这两种方式选一个即可。用了 `default-information originate`，不要再同时对 BGP 做重分发，否则默认路由可能被重复引入，产生环路风险。

### 3. 回程路由要靠 `network`

默认路由只解决了"去程"，回程要靠 R1 的 `network 2.2.2.2`、`network 3.3.3.3` 让 ISP 知道怎么回来。如果源地址是 10.0.123.0/24 这类没通告的网段，外部会回不来，要么通告，要么 NAT。

## 五、多 ISP 场景下的默认路由

两个 ISP 都给默认路由时：

- 两条默认路由都进 BGP 表，按 BGP 选路规则选一条最优
    
- 要主备：对其中一条入站设置更高的 LOCAL_PREF
    
    ```cisco
    route-map PREFER-A permit 10
     set local-preference 200
    router bgp 65001
     neighbor <ISP-A> route-map PREFER-A in
    ```
    
- 要负载分担：开 `maximum-paths`，且两条路径的属性要足够接近（同 AS 内、同邻居 AS 时才满足默认条件）
    
- 只靠默认路由的局限：所有流量按同一个出口走，**做不到按目的地选出口**。需要的话让 ISP 另外再给你特定前缀，或者收全表
    

## 六、验证命令

发送端：

```cisco
show ip bgp neighbors 10.0.1.2 advertised-routes
```

部分平台上这里不一定能看到 `default-originate` 产生的路由，以接收端为准。

接收端：

```cisco
show ip bgp 0.0.0.0
show ip route 0.0.0.0
show ip bgp neighbors 10.0.1.1 routes
```

## 七、速记

|要点|结论|
|---|---|
|`default-originate` 的范围|单个邻居|
|默认是否有条件|无条件，加 route-map 才有条件|
|本机 BGP 表|看不到这条路由|
|出站 prefix-list|拦不住它|
|策略应该写在哪|`default-originate route-map` 里|
|`network 0.0.0.0`|需要精确匹配的默认路由，发给所有邻居|
|`redistribute static`|不带默认路由，需加 `default-information originate`|
|接收端|要有下一跳可达，要做入站过滤|
|防泄露|出站只放行自己的前缀|
|多出口|用 LOCAL_PREF 选主备，默认路由本身不能按目的地选路|

拓扑配置
```R1
interface Loopback0
 ip address 8.8.8.8 255.255.255.255

interface GigabitEthernet0/0
 ip address 10.1.1.1 255.255.255.0


router bgp 65001
 bgp router-id 1.1.1.1
 bgp log-neighbor-changes
 network 8.8.8.8 mask 255.255.255.255
 neighbor 10.1.1.2 remote-as 65002
 neighbor 10.1.1.2 default-originate

```

```R2
interface GigabitEthernet0/0
 ip address 10.1.1.2 255.255.255.0


interface GigabitEthernet0/1
 ip address 20.1.1.2 255.255.255.0


router eigrp 90
 network 20.1.1.0 0.0.0.255
 redistribute bgp 65002 metric 10000 10 255 1 1500 route-map B_T_E
 eigrp router-id 2.2.2.2

router bgp 65002
 bgp router-id 2.2.2.2
 bgp log-neighbor-changes
 network 3.3.3.3 mask 255.255.255.255
 network 4.4.4.4 mask 255.255.255.255
 neighbor 10.1.1.1 remote-as 65001

ip prefix-list DEF seq 5 permit 0.0.0.0/0


route-map B_T_E permit 10
 match ip address prefix-list DEF


```

interface Loopback0
