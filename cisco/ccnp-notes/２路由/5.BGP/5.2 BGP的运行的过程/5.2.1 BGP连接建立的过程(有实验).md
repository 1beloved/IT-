## BGP 报文

### 一、基础特点

BGP 基于 **TCP 179 端口**传输,靠 TCP 保证可靠性,所以不需要像 OSPF 那样自己做重传和确认。邻居需要手工配置,不会自动发现。

### 二、五种报文

所有报文都有相同的 19 字节头部:Marker(16 字节)+ Length(2 字节)+ Type(1 字节)。

| 类型（Type）          | 作用                     |
| ----------------- | ---------------------- |
| **OPEN**          | TCP 建立后第一个发送的报文,用来协商参数 |
| **UPDATE**        | 通告新路由、撤销旧路由            |
| **KEEPALIVE**     | 保活,同时用来确认 OPEN         |
| **NOTIFICATION**  | 报告错误,发送后连接立即断开         |
| **ROUTE-REFRESH** | 请求对端重新发送路由,不用重置邻居      |

**OPEN 报文**携带的内容:

- 版本号(4)
- 本端 AS 号
- Hold Time(双方取较小值)
- BGP Router ID
- 可选参数(能力协商,如 4 字节 AS、MP-BGP、Route Refresh)

**UPDATE 报文**包含三部分:

- 撤销路由(Withdrawn Routes)
- 路径属性(AS_PATH、NEXT_HOP、LOCAL_PREF、MED 等)
- 可达前缀(NLRI)

同一个 UPDATE 里的所有 NLRI 共享同一组路径属性。

**KEEPALIVE** 只有报文头,共 19 字节。默认每 60 秒发一次,Hold Time 默认 180 秒。超时没收到任何 KEEPALIVE 或 UPDATE,邻居就会断开。

### 三、邻居建立过程(状态机)

```
Idle → Connect → Active → OpenSent → OpenConfirm → Established
```

1. **Idle**:初始状态,尝试发起 TCP 连接。
2. **Connect**:等待 TCP 三次握手完成。
3. **Active**:TCP 连接失败,正在重试。
4. **OpenSent**:TCP 已建立,已发送 OPEN,等待对端的 OPEN。
5. **OpenConfirm**:收到对端 OPEN 并检查通过,等待对端的 KEEPALIVE。
6. **Established**:邻居建立成功,开始交换 UPDATE。

### 四、两种邻居类型

**eBGP**(不同 AS)

- 默认 TTL=1,所以通常要求直连;非直连需要配置 `ebgp-multihop`。
- 向对端发送路由时,下一跳会改成自己的地址。

**iBGP**(相同 AS)

- 不要求直连,通常用 Loopback 建邻居,配合 `update-source`。
- 水平分割规则:从 iBGP 邻居学到的路由,不会再通告给其他 iBGP 邻居。所以需要全互联、路由反射器(RR)或联盟。
- 默认不修改下一跳,经常需要 `next-hop-self`。

### 五、邻居建不起来的常见原因

- **卡在 Idle**:没有到邻居的路由,或配置了 shutdown。
- **卡在 Active**:TCP 不通,常见于 ACL 阻断 179 端口、update-source 不对、eBGP 多跳没配。
- **卡在 OpenSent**:对端没回 OPEN,可能是对端没配你为邻居。
- **OPEN 阶段被拒**:AS 号不匹配、Router ID 冲突、认证密码不一致。这时会收到 NOTIFICATION。

### 主错误码

|Code|名称|含义|
|---|---|---|
|1|Message Header Error|报文头有问题|
|2|OPEN Message Error|OPEN 报文参数协商失败|
|3|UPDATE Message Error|UPDATE 报文格式或属性有错|
|4|Hold Timer Expired|Hold Time 内没收到 KEEPALIVE 或 UPDATE|
|5|Finite State Machine Error|在不该收到某报文的状态下收到了它|
|6|Cease|主动终止连接（非上述错误）|
|7|ROUTE-REFRESH Message Error|路由刷新报文有误（RFC 7313）|

### 常见子错误码

**Code 1，报文头错误**

- 1 Connection Not Synchronized（Marker 不对）
- 2 Bad Message Length
- 3 Bad Message Type

**Code 2，OPEN 错误**（最常考）

- 1 Unsupported Version Number
- 2 Bad Peer AS：对端 AS 号和本地配置的不一致
- 3 Bad BGP Identifier：Router ID 不合法或冲突
- 4 Unsupported Optional Parameter
- 6 Unacceptable Hold Time
- 7 Unsupported Capability

**Code 3，UPDATE 错误**

- 1 Malformed Attribute List
- 2 Unrecognized Well-known Attribute
- 3 Missing Well-known Attribute
- 4 Attribute Flags Error
- 5 Attribute Length Error
- 6 Invalid ORIGIN Attribute
- 8 Invalid NEXT_HOP Attribute
- 9 Optional Attribute Error
- 10 Invalid Network Field
- 11 Malformed AS_PATH

**Code 5，状态机错误**

- 1 在 OpenSent 状态收到意外报文
- 2 在 OpenConfirm 状态收到意外报文
- 3 在 Established 状态收到意外报文

**Code 6，Cease**（RFC 4486）

- 1 Maximum Number of Prefixes Reached：收到的前缀超过上限
- 2 Administrative Shutdown：管理员 shutdown
- 3 Peer De-configured：邻居配置被删除
- 4 Administrative Reset：管理员 clear 了邻居
- 5 Connection Rejected
- 6 Other Configuration Change
- 7 Connection Collision Resolution
- 8 Out of Resources
