
#### （1）Cisco 设备的权限特点

- Telnet 登录后：
  - 默认进入 **用户模式**（`>`），只能查看少量信息
  - 需要输入 `enable` 并再输入 enable 密码，才能进入 **特权模式**（`#`）
  - 如果没配 enable 密码，可能无法进入特权模式，管理受限

#### （2）Telnet 认证方式

Cisco 设备上 Telnet 常见两种认证：

| 方式 | 说明 |
|------|------|
| `login local` | 使用本地用户名/密码认证（推荐） |
| `login` + `password` | 只配 vty 密码，不区分用户 |

推荐配置：

```cisco
username admin privilege 15 secret cisco123
line vty 0 4
 login local
 transport input telnet
```

这样登录后可直接进入特权模式，权限足够。

#### （3）Telnet 实验配置示例

```cisco
! 1. 配置管理 IP
interface Vlan1
 ip address 192.168.1.1 255.255.255.0
 no shutdown

! 2. 配置特权密码
enable secret cisco123

! 3. 配置本地用户
username admin privilege 15 secret cisco123

! 4. 开启 Telnet
line vty 0 4
 login local
 transport input telnet

! 5. 验证
! PC 上 telnet 192.168.1.1
```

### 3.2 SSH 服务

#### 1. SSH 是什么

- **Secure Shell**，安全的远程登录协议
- 数据**加密传输**
- 基于 **TCP 协议**
- 默认端口 **22**

#### 2. SSH 相比 Telnet 的优势

- 加密：用户名、密码、命令内容都加密
- 完整性校验：防止数据被篡改
- 身份认证更强：支持密钥认证

👉 真实生产环境**必须用 SSH**，Telnet 只用于实验。

#### 3. Cisco SSH 配置示例

```cisco
! 1. 设置主机名和域名（生成密钥需要）
hostname R1
ip domain-name example.com

! 2. 生成 RSA 密钥
crypto key generate rsa
! 提示密钥长度时输入 1024 或 2048

! 3. 配置用户
username admin privilege 15 secret cisco123

! 4. 配置 SSH 版本
ip ssh version 2

! 5. 在 vty 上只允许 SSH
line vty 0 4
 login local
 transport input ssh
```

验证：

```text
PC> ssh -l admin 192.168.1.1
```

### 3.3 Telnet 与 SSH 对比小结

| 对比项 | Telnet | SSH |
|--------|--------|-----|
| 端口 | 23 | 22 |
| 加密 | 明文 | 加密 |
| 安全性 | 低 | 高 |
| 使用场景 | 实验/临时 | 生产环境 |
| 配置复杂度 | 简单 | 稍复杂（需生成密钥） |

## 四、DHCP 服务（分配）

### 4.1 为什么需要 DHCP

手工配 IP 的问题：

- 主机多时工作量大
- 容易配错、冲突
- 移动终端不方便

DHCP 可以自动分配：

- IP 地址
- 子网掩码
- 网关
- DNS

### 4.2 DHCP 工作过程（DORA）

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | Discover | 客户端广播找 DHCP 服务器 |
| 2 | Offer | 服务器提供可用 IP |
| 3 | Request | 客户端请求使用该 IP |
| 4 | Ack | 服务器确认分配 |

### 4.3 DHCP 三种部署方式

| 方式                    | 说明                               | 适用场景 |
| --------------------- | -------------------------------- | ---- |
| 路由器作 DHCP 服务器         | 路由器直接配地址池                        | 小型网络 |
| 三层交换机作 DHCP 服务器       | SVI 上配地址池                        | 中型网络 |
| 专用 DHCP 服务器 + DHCP 中继 | 服务器统一管理，跨网段用 `ip helper-address` | 大型网络 |
|                       |                                  |      |

### 4.4 路由器 DHCP 配置示例

```cisco
! 开启 DHCP 服务
service dhcp

! 配置地址池
ip dhcp pool LAN10
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8

! 排除网关等固定地址
ip dhcp excluded-address 192.168.10.1 192.168.10.10
```

### 4.5 DHCP 中继配置示例

当 DHCP 服务器和客户端不在同一网段：

```cisco
interface Vlan10
 ip address 192.168.10.1 255.255.255.0
 ip helper-address 192.168.100.100   ! 指向 DHCP 服务器
```

## 五、数据传输服务（传输）

### 5.1 为什么需要可靠/高效传输

不同业务对传输要求不同：

- 文件传输、邮件：要求**可靠**，不能丢
- 语音、视频：要求**高效**，能容忍少量丢包

### 5.2 TCP 与 UDP 对比

| 对比项 | TCP | UDP |
|--------|-----|-----|
| 连接方式 | 面向连接 | 无连接 |
| 可靠性 | 可靠（确认、重传） | 不可靠 |
| 速度 | 较慢 | 较快 |
| 开销 | 大 | 小 |
| 典型应用 | HTTP、FTP、SSH、Telnet | DNS、DHCP、语音、视频 |

### 5.3 常见端口号

| 协议 | 端口 | 传输层 |
|------|------|--------|
| Telnet | 23 | TCP |
| SSH | 22 | TCP |
| HTTP | 80 | TCP |
| HTTPS | 443 | TCP |
| FTP | 20/21 | TCP |
| DNS | 53 | UDP/TCP |
| DHCP | 67/68 | UDP |
| TFTP | 69 | UDP |
