把多个物理上的接口捆版为逻辑上的虚拟接口，作用：
1.增加带宽
2.负载分担
3.故障切换

一般有三个模式
1.手工   on   ```
```
channel-group 1 mode on
```
2.LACP (共有协议)
```
channel-group 1 mode active   主动模式
channel-group 1 mode passive  被动模式
```

3.PAGP(CISCO私有)
```
channel-group 1 mode auto     被动模式
channel-group 1 mode desireable  主动模式
```

1. 思科交换机（特别是2960、3560等型号）要求：必须先指定Trunk封装协议（`dot1q` 或 `isl`），才能将端口模式设置为 `trunk`**。如果顺序反了，或者只改了模式没改封装，就会出现你遇到的兼容性报错。
    
2. 更稳妥的配置习惯
    建议在配置链路聚合时，把相关命令写在同一段配置中，或者一次性在接口范围（`if-range`）下完整输入，避免分步操作引发不必要的端口震荡。
    
    Switch(config)# interface range gi0/0-1
    Switch(config-if-range)# switchport trunk encapsulation dot1q
    Switch(config-if-range)# switchport mode trunk
    Switch(config-if-range)# channel-group 1 mode active
```
