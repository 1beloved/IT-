

### 4.1 脚本基础

```bash
#!/usr/bin/env bash        # shebang，指定解释器
echo 'hello'
```

```bash
chmod +x a.sh && ./a.sh    # 或 bash a.sh
bash -x a.sh               # 调试：打印每条执行的命令
```

建议头部加 `set -u`（使用未定义变量报错）；熟练后可用 `set -euo pipefail`（出错即退出、管道任一环失败即失败）。

### 4.2 变量

```bash
name='web1'                 # 等号两边不能有空格！
echo $name ${name}_01       # 拼接字符时用 ${}
now=$(date '+%F %T')        # 命令替换
export ENV=prod             # 导出为环境变量，子进程可见
files=(a.log b.log c.log)   # 数组
echo ${files[0]} ${#files[@]} ${files[@]}
```

特殊变量：`$0` 脚本名，`$1..$9` 参数，`$#` 参数个数，`$@` 所有参数，`$?` **上一条命令的退出码（0 成功，非 0 失败）**，`$$` 当前 PID。

引用规则：双引号内变量会展开，单引号内原样输出；**变量一律加双引号**（`"$var"`），防止空格和空值出问题。

### 4.3 条件判断

```bash
if [[ -f /etc/nginx/nginx.conf ]]; then
    echo 'exists'
elif [[ -d /etc/nginx ]]; then
    echo 'dir only'
else
    echo 'missing'
fi
```

|   |   |
|---|---|
|类型|写法|
|文件|`-e` 存在，`-f` 普通文件，`-d` 目录，`-r/-w/-x` 可读写执行，`-s` 非空|
|数字|`-eq -ne -gt -ge -lt -le`|
|字符串|`==`、`!=`、`-z`（为空）、`-n`（非空）|
|逻辑|`&&`、`\|`、`!`|

```bash
case "$1" in
    start) echo starting ;;
    stop)  echo stopping ;;
    *)     echo "usage: $0 {start|stop}" ;;
esac
```

命令成功与否也可直接做条件：`if systemctl is-active --quiet nginx; then ...`。

### 4.4 循环与函数

```bash
for s in sshd nginx cron; do
    systemctl is-active --quiet "$s" && echo "$s OK" || echo "$s FAIL"
done

while read -r line; do        # 逐行读文件
    echo "$line"
done < hosts.txt

for i in $(seq 1 5); do echo $i; done
```

函数：

```bash
log() { echo "[$(date '+%F %T')] $*"; }
log 'start check'
```

`break` 跳出循环，`continue` 跳过本次。函数返回值用 `return N`（0-255），要返回字符串就 `echo` 再用 `$()` 接收。

### 4.5 文本处理三剑客与日志筛选

```bash
grep -n 'error' f                  # 行号
grep -i -E 'error|fail' f          # 忽略大小写 + 正则或
grep -v 'debug' f                  # 反向
grep -C 3 'OOM' f                  # 前后各 3 行上下文

awk '{print $1, $9}' f             # 按空白分列取字段
awk -F: '{print $1, $3}' /etc/passwd   # 指定分隔符
awk '$9 >= 500' access.log         # 条件过滤
awk '{s+=$10} END {print s}' f     # 求和

sed 's/old/new/g' f                # 替换（输出到屏幕）
sed -i 's/old/new/g' f             # 原地修改（先备份！）
sed -n '10,20p' f                  # 打印 10-20 行

cut -d: -f1 /etc/passwd; sort -u; uniq -c; tr 'a-z' 'A-Z'
```

经典组合 **统计频次**：`... | sort | uniq -c | sort -nr | head`。

示例：找出一小时内失败登录最多的 IP：

```bash
grep 'Failed password' /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr | head -5
```

### 4.6 定时任务 cron

```bash
crontab -e     # 编辑当前用户任务
crontab -l     # 查看
```

格式：`分 时 日 月 周 命令`

```
0 8 * * *      每天 8:00
*/5 * * * *    每 5 分钟
30 2 * * 0     每周日 2:30
0 3 1 * *      每月 1 号 3:00
```

**cron 的坑**：

- 环境变量极简，PATH 与登录 shell 不同 → **命令和脚本一律写绝对路径**。
- 默认没有输出可看 → 一定重定向：`>> /var/log/job.log 2>&1`。
- 脚本要有执行权限，且首行写好 shebang。
- 没执行时先看服务与日志：`systemctl status cron`（RHEL 系 `crond`），`grep CRON /var/log/syslog`。
- 进阶：systemd timer 也能定时，日志统一进 journal。

### 4.7 综合项目：服务器巡检脚本

**需求**：检查系统负载、内存、磁盘、关键服务、关键端口、近期失败登录，输出到日志并标记 OK / WARN / FAIL，每天早上自动执行。

`/opt/scripts/server_check.sh`：

```bash
#!/usr/bin/env bash
# 服务器巡检脚本
set -u

LOG_DIR=/var/log/server_check
REPORT=$LOG_DIR/report_$(date +%F).log
MEM_WARN=80
DISK_WARN=80
SERVICES=(ssh nginx cron)    # RHEL 系把 ssh 改成 sshd
PORTS=(22 80)

mkdir -p "$LOG_DIR"
log() { echo "[$(date '+%F %T')] $*" | tee -a "$REPORT"; }

check_system() {
    log '== 系统信息 =='
    log "主机: $(hostname)  内核: $(uname -r)  运行: $(uptime -p)"
    log "负载(1/5/15分钟): $(cut -d' ' -f1-3 /proc/loadavg)"
}

check_mem() {
    local pct
    pct=$(free | awk '/Mem:/ {printf "%d", $3/$2*100}')
    if [[ $pct -ge $MEM_WARN ]]; then log "[WARN] 内存使用 ${pct}%"; else log "[OK] 内存使用 ${pct}%"; fi
}

check_disk() {
    log '== 磁盘 =='
    df -hP | awk 'NR>1 {print $5, $6}' | while read -r use mnt; do
        pct=$(echo "$use" | tr -d '%')
        if [[ $pct -ge $DISK_WARN ]]; then log "[WARN] $mnt 使用 ${pct}%"; else log "[OK] $mnt 使用 ${pct}%"; fi
    done
}

check_services() {
    log '== 服务 =='
    for s in "${SERVICES[@]}"; do
        if systemctl is-active --quiet "$s"; then log "[OK] 服务 $s 运行中"; else log "[FAIL] 服务 $s 未运行"; fi
    done
}

check_ports() {
    log '== 端口 =='
    for p in "${PORTS[@]}"; do
        if ss -tln | grep -q ":$p "; then log "[OK] 端口 $p 监听中"; else log "[FAIL] 端口 $p 未监听"; fi
    done
}

check_logins() {
    log '== 失败登录 TOP5（来源 IP）=='
    grep 'Failed password' /var/log/auth.log 2>/dev/null \
        | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr | head -5 | tee -a "$REPORT"
}

main() {
    check_system; check_mem; check_disk
    check_services; check_ports; check_logins
    log "巡检完成，报告：$REPORT"
}
main
```

运行与定时：

```bash
sudo chmod +x /opt/scripts/server_check.sh
sudo /opt/scripts/server_check.sh
sudo crontab -e
# 0 8 * * * /opt/scripts/server_check.sh >> /var/log/server_check/cron.log 2>&1
```

**进阶方向**：失败时发邮件或 webhook 通知、清理 7 天前的报告、把检查项改成读配置文件、用参数控制只检查某一项。
