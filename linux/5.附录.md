## 附录

### A. 高频面试题（自测）

1. `kill` 和 `kill -9` 的区别？（15 与 9，优雅退出 vs 强杀）
2. 软链接和硬链接的区别？（软链接是指向路径的快捷方式，硬链接是同一 inode 的另一个名字，不能跨分区）
3. 磁盘显示还有空间却写不进去？（inode 用尽 / 被删除文件仍被占用 / 配额）
4. 服务起不来怎么排查？（`systemctl status` → `journalctl -u` → 配置语法检查 → 端口占用 → 权限 / SELinux）
5. 外部访问不了但本机可以？（监听地址、防火墙、云安全组）
6. `Connection refused` 和 `timeout` 区别？
7. `reload` 与 `restart` 区别？
8. 如何查看某端口被谁占用？（`ss -tulnp`、`lsof -i :端口`）
9. 怎么查看系统负载高的原因？（`uptime` → `top` 看 CPU / D 状态 / IO → `free` → `df`）
10. cron 任务没执行怎么查？（绝对路径、权限、日志重定向、cron 服务与日志）

### C. 常用命令速查

```
文件：ls cd pwd cp mv rm find ln tar
文本：cat less head tail grep awk sed sort uniq wc cut
权限：chmod chown umask sudo useradd usermod passwd id
进程：ps top kill pgrep nohup free uptime
磁盘：df du lsblk mount fdisk mkfs lsof
服务：systemctl journalctl
网络：ip ss ping traceroute dig curl nc tcpdump
防火墙：ufw firewall-cmd iptables
包管理：apt dnf dpkg rpm
```
