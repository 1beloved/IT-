


**目标：不靠图形界面，独立完成文件管理、权限设置、用户管理、装软件、看进程、查磁盘。**

### 1.1 目录结构（FHS）

|   |   |   |
|---|---|---|
|目录|作用|记忆点|
|`/`|根目录|一切的起点|
|`/etc`|配置文件|改配置先来这里|
|`/var`|经常变化的数据|`/var/log` 日志，`/var/lib` 服务数据|
|`/home`、`/root`|普通用户 / root 的家目录||
|`/usr`、`/opt`|软件安装位置|`/opt` 常放第三方软件|
|`/bin`、`/sbin`|基础命令|新系统里是 `/usr/bin` 的软链接|
|`/tmp`|临时文件|重启可能清空|
|`/proc`、`/sys`|内核虚拟文件系统|`cat /proc/loadavg`|
|`/dev`|设备文件|`/dev/sda`、`/dev/null`|
|`/mnt`、`/media`|挂载点||

核心认知：**一切皆文件**；配置在 `/etc`，日志在 `/var/log`，数据在 `/var/lib`。

路径写法：绝对路径以 `/` 开头；相对路径相对当前目录；`.` 当前目录，`..` 上一级，`~` 家目录，`cd -` 回到上一次目录。

### 1.2 文件与目录操作

```bash
pwd                      # 当前目录
ls -lah                  # 详细列表，含隐藏文件，人类可读大小
cd /etc/nginx            # 切换目录
mkdir -p a/b/c           # 递归创建
touch file.txt           # 创建空文件 / 更新时间戳
cp -r src dst            # 复制目录要加 -r；保留属性用 cp -a
mv old new               # 移动或重命名
rm file; rm -rf dir      # 删除（-rf 无确认，极其危险）
ln -s /real/path link    # 软链接
```

**铁律**：`rm -rf` 前先 `ls` 确认；永远不要手滑敲 `rm -rf /` 或 `rm -rf /*`；删除带变量的路径要确认变量非空。

查找文件：

```bash
find /var/log -name '*.log' -mtime -1        # 一天内修改过的日志
find / -size +100M 2>/dev/null               # 大于 100M 的文件
find /tmp -type f -mtime +7 -delete          # 删除 7 天前的文件
which nginx; whereis nginx                   # 命令位置
```

### 1.4 重定向与管道

```bash
cmd > f        # 覆盖写入标准输出
cmd >> f       # 追加
cmd 2> err.log # 错误输出
cmd > f 2>&1   # 正确+错误都写入 f
cmd > /dev/null 2>&1   # 丢弃所有输出（cron 常用）
cmd1 | cmd2    # 管道：前者输出作后者输入
cmd | tee f    # 屏幕显示同时写文件
```

示例：`ps aux | grep nginx | grep -v grep | wc -l`（统计 nginx 进程数）。

### 1.5 权限

```
-rwxr-xr--  1 alice dev  1024 Oct 12 10:00 run.sh
│└┬┘└┬┘└┬┘     │     └─ 属组
│ │  │  └ 其他人权限      └─ 属主
│ │  └ 属组权限
│ └ 属主权限
└ 类型：- 文件，d 目录，l 链接
```

数字权限：**r=4，w=2，x=1**。`755 = rwxr-xr-x`，`644 = rw-r--r--`，`600 = rw-------`。

```bash
chmod 755 run.sh; chmod u+x run.sh; chmod -R 644 dir/
chown alice:dev file; chown -R www-data:www-data /var/www/demo
umask                    # 默认掩码，常见 022（文件默认 644，目录 755）
```

**目录上的权限含义**：`r` 能列出文件名，`w` 能创建/删除其中文件，`x` 能进入目录。进不去目录先检查路径上每一级的 `x`。

特殊权限（了解）：SUID（`4xxx`，以属主身份运行，如 `passwd`）、SGID（`2xxx`）、Sticky（`1xxx`，如 `/tmp`，只能删自己的文件）。

`sudo`：以管理员身份执行；授权配置文件 `/etc/sudoers`，**必须用 `visudo` 编辑**（有语法检查，改坏了会锁死 sudo）。

### 1.6 用户与组

```bash
sudo useradd -m -s /bin/bash ops   # 创建用户（-m 建家目录）
sudo passwd ops                    # 设置密码
sudo usermod -aG sudo ops          # 加入附加组（RHEL 系用 wheel）。-a 不能漏！
sudo userdel -r ops                # 删除用户及家目录
id ops; groups ops; whoami
su - ops                           # 切换用户并加载其环境
```

Ubuntu 也可用交互式的 `adduser`。关键文件：

- `/etc/passwd`：`用户名:x:UID:GID:说明:家目录:Shell`，UID 0 是 root，普通用户通常 ≥1000。
- `/etc/shadow`：加密后的密码（仅 root 可读）。
- `/etc/group`：组信息。

坑：`usermod -G` 不带 `-a` 会**覆盖**原有附加组。

### 1.7 软件包管理

|   |   |   |
|---|---|---|
|操作|Ubuntu / Debian|RHEL 系|
|刷新索引|`apt update`|`dnf makecache`|
|安装|`apt install nginx`|`dnf install nginx`|
|升级|`apt upgrade`|`dnf upgrade`|

压缩与下载：

### 1.8 进程管理

```bash
ps aux | grep nginx   # 所有进程（a 所有用户 u 详细 x 无终端的）
ps -ef --forest       # 看父子关系
top                   # 实时；按 P 排 CPU，M 排内存，q 退出（htop 更好用）
pgrep -a nginx        # 按名字找 PID
kill PID              # 默认 SIGTERM(15)，请求优雅退出
kill -9 PID           # SIGKILL，强杀，最后手段
pkill -f 'python app.py'
nohup cmd > out.log 2>&1 &   # 后台运行，退出终端不中断
jobs; bg; fg          # 作业控制
free -h; uptime       # 内存 / 负载
```

- **load average** 三个数字是 1/5/15 分钟平均负载，和 CPU 核数对比：4 核机器长期超过 4 就偏高。
- 进程状态：`R` 运行、`S` 可中断睡眠、`D` 不可中断（通常卡 IO）、`Z` 僵尸（杀不掉，需处理父进程）、`T` 停止。
- 长期运行的服务不要靠 `nohup`，应交给 systemd（第 2 周）。

### 1.9 磁盘管理

```bash
df -h                 # 各分区使用率
df -i                 # inode 使用率（小文件太多也会「满」）
du -sh /var/*         # 目录大小
du -ah /var | sort -rh | head -20   # 找最大的文件/目录
lsblk; blkid          # 块设备、UUID
mount; umount /mnt/data
```

**新增一块磁盘的标准流程**：

```bash
sudo fdisk /dev/sdb        # n 新建分区 → w 保存
sudo mkfs.ext4 /dev/sdb1   # 格式化
sudo mkdir /data && sudo mount /dev/sdb1 /data
blkid /dev/sdb1            # 拿 UUID
# /etc/fstab 追加： UUID=xxxx  /data  ext4  defaults  0 2
sudo mount -a              # 验证 fstab 没写错（写错可能导致无法开机）
```

LVM 概念（了解）：物理卷 PV → 卷组 VG → 逻辑卷 LV，优点是可在线扩容。

**「磁盘满了」排查链**：`df -h` 找满的分区 → `du -sh` 逐层下钻 → 常见元凶是 `/var/log`、容器、备份 → 若删了大文件空间不释放，用 `lsof +L1` 找「已删除但仍被进程占用」的文件，重启该进程即可。
